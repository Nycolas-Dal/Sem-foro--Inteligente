# 🚦 Semáforo Inteligente

Um projeto de **Semáforo Inteligente** desenvolvido com HTML, CSS e JavaScript, com o objetivo de apresentar uma solução tecnológica voltada para a melhoria da mobilidade urbana e organização do trânsito.

## 📌 Sobre o projeto

O **Semáforo Inteligente** é um projeto que busca demonstrar como a tecnologia pode ser utilizada para tornar o controle do trânsito mais eficiente.

O site apresenta informações sobre o projeto e uma galeria com imagens do protótipo, tecnologia, funcionamento e resultado final.

## ✨ Funcionalidades

* 🎨 Interface moderna com tema azul-escuro
* 🚦 Representação visual de um semáforo
* 📱 Design responsivo para computadores, tablets e celulares
* 🖼️ Galeria com 4 imagens do projeto
* ✨ Animações nos cards
* 🔗 Navegação pela página através da navbar
* 📐 Layout adaptável a diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura da página
* **CSS3** — Estilização, layout e responsividade
* **JavaScript** — Animações e interatividade

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/semaforo-inteligente.git
```

### 2. Entre na pasta

```bash
cd semaforo-inteligente
```

### 3. Abra o projeto

Abra o arquivo:

```text
index.html
```

Você pode abrir diretamente no navegador ou utilizar uma extensão como **Live Server** no VS Code.

## 🖼️ Adicionando imagens

As imagens devem ficar dentro da pasta `imagens` e seguir os nomes:

```text
foto1.jpeg
foto2.jpeg
foto3.jpeg
foto4.jpeg
```

Caso queira utilizar outros nomes, altere os caminhos das imagens no arquivo `index.html`.
